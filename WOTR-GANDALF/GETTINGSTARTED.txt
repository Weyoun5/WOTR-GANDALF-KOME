WAR OF THE RING - v1.12

1. Extract the entire ZIP. Keep the WOTR-GANDALF asset subfolders intact.
2. Install Java 8 or newer, then open WOTR-GandalfV8-KoME.jar.
3. Choose File > New game and select the expansions and promos to use.
4. Both players must use the same gameplay build and expansion selection.

File > Settings contains appearance, combined WoME hands, and event audio.
Event music can be enabled there; it has its own volume control.
The sovereign board opens automatically for Kings; Ctrl+K reopens it.
